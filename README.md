# LipiGhor Server

LipiGhor Backend — An AI-powered Bangla Font Discovery & Download Platform. Built with Node.js, Express, TypeScript, MongoDB/Mongoose, and OpenRouter.

## Project Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**:
   Copy `.env.example` to `.env` and fill in the required keys.
   ```bash
   cp .env.example .env
   ```

3. **Development Mode**:
   ```bash
   npm run dev
   ```

4. **Production Build**:
   ```bash
   npm run build
   npm start
   ```

5. **Run Tests**:
   ```bash
   npm run test
   ```
